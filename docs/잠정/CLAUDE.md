# 잠정/ — 5장 정본 · 결정이 안 났는데 진행은 해야 할 때

> 이 폴더는 ★항상 비어가는 폴더다★ — 늘기만 하면 그건 방침 문제가 아니라
> **결정대장 ①절이 안 비고 있다는 신호**다.
> 계기와 장 지도는 루트 CLAUDE.md 에 있다. 최종 확인: 2026-08-12

## 5. 잠정 방침

결정대장은 **안 정한 것**을, 사건 문서는 **한 것**을 담는다.
그 사이가 비어 있다 — **안 정한 채로 갔을 때 무엇을 가정하고 갔는지.**
그건 코드에만 남고 문서에는 안 남는다.

```
잠정/방침_이름.md      이름 고정 · 날짜 없음
```

### 머리말 네 칸

```
잠정 근거:   어느 결정이 안 나서 이게 필요한가 — ★결정대장 ①-N 링크★
방침:        그래서 무엇을 어떻게 하겠다 — 한 문단, 명령형으로
뒤집힘 비용: 결정이 반대로 나면 무엇을 되돌려야 하나 — 파일·작업량으로
적용 범위:   어디까지 따르나 / 어디부터는 안 따르나
```

**`뒤집힘 비용` 이 핵심이다.** 4장의 `막히는 것` 과 짝이다 —

```
막히는 것    안 정하면 못 가는 것        → 결정을 ★앞당길★ 이유
뒤집힘 비용  일단 갔다가 물릴 때의 값     → 결정을 ★미룰 수 없는★ 이유
```

둘이 같이 있어야 사용자가 "이걸 지금 답해야 하나"를 판단할 수 있다.
하나만 있으면 ①절은 "언젠가"의 목록으로 남는다.

### 양방향 링크 — 이게 없으면 방침이 안 죽는다

```
결정대장 ①-N 행   →  잠정: 잠정/X.md
잠정/X.md 머리말   →  이 방침을 죽이는 결정: ①-N
```

**왜**: 결정이 마침내 났을 때 "그 방침을 손봐야 한다"고 알려주는 건 이 역링크뿐이다.
없으면 방침은 조용히 살아남아 **결정을 이긴다.**

### 죽는 길

```
결정이 방침대로 났다    → 방침 내용을 상시 문서로 승격 · 잠정/ 에서 지운다
결정이 다르게 났다      → '뒤집힘 비용' 을 진행중/ 사건 문서로 · 잠정/ 에서 지운다
결정 필요가 사라졌다    → 그냥 굳은 것이다. 상시로 승격 · 지운다
```
