# 원본/ — 원자료. 한 글자도 안 고친다

> 계기와 장 지도는 루트 CLAUDE.md 에 있다. 최종 확인: 2026-08-12

- **받은 그대로 보관한다.** 정리·수정은 사본(`회의록/`)에서만 한다 → 회의록/CLAUDE.md 의 7장.
- 월 폴더와 파일명을 사본과 똑같이 맞춘다 — `원본/회의/YYYY-MM/YYYY-MM-DD_회의명.md`.
- 안의 옛 표기는 당시 사실이다 — 고치면 안 된다 (11장).
- **나가면 안 되는 내용이면 애초에 넣지 않는다** — 들어온 뒤에 지우는 길은 이 규약에 없다 (7장).
