
★벌 수가 다른 경우들★ — 뜬 시점까지만 있는 게 정상이다:

```

```

```
진행중 스냅샷  종결 정리(6장 ③④)가 실행 기록을 덮는 것을 막는다
```

대개 같아도 뜬다 (04_규약근거.md 16장). git 이 있어도 뜬다 — 겹치는 건 보관이지
역할이 아니다 (04_규약근거.md 16장).

## 규칙

- **받은/있던 그대로 보관한다.** 여기 들어온 파일은 어떤 이유로도 안 고친다.
- 안의 옛 표기는 당시 사실이다 — 고치면 안 된다 (11장).
- **여기서 링크가 깨져도 안 고친다** — 깨진 링크 자체가 "그때는 저기 있었다"는 정보다.
  (종결/ 은 반대다 — 15장의 예외 하나.)
- 회의 원본의 정리·수정은 사본(`회의록/`)에서만 한다 → 회의록/CLAUDE.md 의 7장.
- **나가면 안 되는 내용이면 애초에 넣지 않는다** — 들어온 뒤에 지우는 길은 이 규약에
  없다. 잠정·진행중 문서에 키·비밀번호를 적으면 그대로 여기 박힌다 (3장의 대괄호 치환).
