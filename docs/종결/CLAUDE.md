# 종결/ — 동결. 손대지 않는 곳 · 15장 정본

> 장문 근거는 04_규약근거.md 15장 — 판정이 애매할 때만 그 장을 연다.
> 계기와 장 지도는 루트 CLAUDE.md 에 있다. 최종 확인: 2026-08-17
> 반증 조건: 없음 — 규칙은 합의다 (13장)
> 재론 조건: ★종결 문서를 고치고 싶어졌을 때★ · [종결]과 [폐기]의 취급이 달라져야 할 때

## 15. 동결과 재작업 사이클

```
여기 문서는 ★지우지도 고치지도 않는다★ — 그날의 실측과 계획과의 차이가 여기 있다
★[폐기] 문서도 여기 산다★ — 취급이 같기 때문이다 (1장 · 폴더를 더 쪼개지 않는다)
`YYYY-MM/` 으로 가른다 — 월 폴더는 ★파일명의 YYYY-MM★ (= 잠정에서 태어난 달)
  → 스냅샷(있는 만큼)과 종결본이 같은 월 폴더에 놓여 짝인지 눈으로 보인다 (2장·16장)
```

여기 문서는 세 종류이고 답하는 질문이 다르다 — 구분은 머리말 표기뿐이다:

```
[종결]           "그날 무엇을 했고 무엇을 쟀나"
[폐기] (진행중발) "무엇을 하다가 왜 접었나"      6장 절차를 밟았다 · 스냅샷 두 벌
                                               (관문 누락 복구였으면 한 벌 — 16장)
[폐기] (잠정발)   "무엇을 하려다 왜 안 했나"      그대로 얼었다 · ★스냅샷 없는 게 정상★ (5장)
```

## 수정할 거리가 생기면 — ★고치지 않는다 · 활성/유예를 판정한다★

```
지금 다시 하기로 합의했다   → 잠정/ 에 새 사이클 (아래)
명시적으로 유예됐다         → 백로그 항목으로 (0장)
새 합의가 없다              → 파생 문서를 만들지 않는다 — 거리는 회의록·대화에 남는다
```

```
종결/2026-08/2026-08-12_ASOS수집.md      ← 그대로 둔다. 한 글자도 안 고친다
                    │
                    ▼  "결측 처리를 다시 하기로 했다"
잠정/2026-09-03_ASOS결측처리.md          ← 새 사이클 · 머리말에 한 줄:
    앞 사이클: 종결/2026-08/2026-08-12_ASOS수집.md
```

이름에 차수를 넣지 않는다 (`…_2차_보완` 금지) — ★연결은 이름이 아니라 링크가 한다★.

```
종결 문서가 답하는 질문   "그날 무엇을 했고 무엇을 쟀나"
새 잠정이 답하는 질문     "그래서 지금 무엇을 하기로 했나"
```

한 문서가 둘 다 답하려 하면 둘 다 틀린다 — 그래서 오타조차 안 고친다
(04_규약근거.md 15장). "지금 유효한 것"은 종결/ 이 아니라 상시 문서(`NN_…`)가
갖는다 (13장) — 종결 문서가 낡는 것은 고장이 아니라 설계다.
