> 반증 조건: 없음 — 규칙은 합의다 (13장)
> 재론 조건: ★종결 문서를 고치고 싶어졌을 때★ · [종결]과 [폐기]의 취급이 달라져야 할 때

## 15. 동결과 재작업 사이클

```
여기 문서는 ★지우지도 고치지도 않는다★ — 그날의 실측과 계획과의 차이가 여기 있다
★[폐기] 문서도 여기 산다★ — 취급이 같기 때문이다 (폴더를 더 쪼개지 않는다 · 1장)
`YYYY-MM/` 으로 가른다 — 계속 쌓이는 곳이라 flat 이면 목록 구실을 못 한다 (2장)
월 폴더는 ★파일명의 YYYY-MM★ 을 따른다 (= 잠정에서 태어난 달, 종결한 달이 아니다)
```

**여기 문서는 세 종류이고, 답하는 질문이 각각 다르다** — 구분은 머리말 표기뿐이다:

```
[종결]           "그날 무엇을 했고 무엇을 쟀나"
[폐기] (진행중발) "무엇을 하다가 왜 접었나"      6장 절차를 밟았다 · 스냅샷 두 벌
[폐기] (잠정발)   "무엇을 하려다 왜 안 했나"      그대로 얼었다 · ★스냅샷 없는 게 정상★ (11장)
                 ─ 잠정에도 `## 실행` 이 있을 수 있다 (5장). 스냅샷이 없는 이유는
                   실행 유무가 아니라 ★뒤에 다시 쓰는 단계가 없어서★다
```

**왜 태어난 달로 가르나** — ★2장 정본★. 결론만 옮기면: 스냅샷 둘과 종결본이
같은 월 폴더에 놓여 **셋이 짝인지 눈으로 보인다** (11장).

## 수정할 거리가 생기면 — ★새 잠정을 연다★

```
종결/2026-08/2026-08-12_ASOS수집.md      ← 그대로 둔다. 한 글자도 안 고친다
                    │
                    ▼  "결측 처리를 다시 하기로 했다"
잠정/2026-09-03_ASOS결측처리.md          ← 새 사이클이 여기서 태어난다
    앞 사이클: 종결/2026-08/2026-08-12_ASOS수집.md
```

새 문서 머리말에 **`앞 사이클:` 한 줄**을 단다. 이름에는 안 넣는다 —
`…_수집_2차_보완_재작업.md` 는 3차·4차에서 무너진다. **연결은 이름이 아니라 링크가 한다.**

### 왜 고치지 않나

```
종결 문서가 답하는 질문   "2026-08-12 에 무엇을 했고 무엇을 쟀나"
새 잠정이 답하는 질문     "그래서 지금 무엇을 하기로 했나"
```

**둘은 다른 질문이고, 한 문서가 둘 다 답하려 하면 둘 다 틀린다.**
종결본을 고치면 그날의 실측이 오늘의 이해로 덮이고, 그러면 *"그때는 왜 그렇게 봤나"* 가
사라진다 — 나중에 그 결론을 뒤집어야 할 때 필요한 게 정확히 그것이다 (3장).

**"지금 유효한 것"은 종결/ 가 갖지 않는다.** 그건 상시 문서(`NN_…`)가 갖는다 (13장).
종결 문서가 낡는 것은 고장이 아니라 **설계다** — 낡으라고 만든 문서다.

### 예외는 하나뿐

**링크 경로 수선.** 가리키던 파일이 옮겨져 깨진 링크는 고친다.
내용은 아니다. 그밖에는 오타조차 고치지 않는다 — 손대는 습관이 생기는 순간
"이 정도는 괜찮다"의 경계가 매번 새로 그어진다.
