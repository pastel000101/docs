# 진행중/ — 사건의 탄생과 종결 · 3 · 6장 정본

> 이 폴더는 ★비어 있는 게 정상★이다. 월별로 가르지 않는다 —
> "몇 건이나 열려 있나"가 한눈에 보여야 한다 (2장).
> 계기와 장 지도는 루트 CLAUDE.md 에 있다. 최종 확인: 2026-08-12

## 3. 사건 문서는 태어날 때 머리말 세 칸을 적는다

```
계기:         왜 열렸나 — ★사용자 말 원문 그대로★ (요약 금지)
종결 조건:    누가 무엇을 보면 닫나 — 가능하면 숫자로
상시로 갈 것: (빈 칸으로 시작 — 작업 중에 한 줄씩 쌓는다)
```

- **종결 조건이 없으면** 문서는 안 닫히고 폴더만 는다.
  관찰자와 관찰 대상을 적는다 — "무엇이 확인되면"보다 "누가 무엇을 보면"이 실제로 지켜진다.
- **계기가 없으면** 결론만 남고 *"왜 그때 그렇게 정했나"* 가 날아간다 —
  나중에 그 결론을 뒤집어야 할 때 필요한 게 정확히 그것이다.
- ★요약하면 값이 사라진다★. 원문 한 문장이 결론 전체를 지탱하는 경우가 흔하다.

### `상시로 갈 것` — 작업 중에 적립한다

"이건 이 작업이 끝나도 남는 지식이다" 싶은 게 나오면 **그 순간 한 줄** 적는다.
어디로 옮길지까지 적으면 종결 때 판단이 필요 없다.

**왜**: 이 규약에서 **되돌릴 수 없는** 단계가 6장 ② (지식 이관)인데, 그걸
문서를 빨리 닫고 싶은 순간에 요구하면 건너뛴다. 판별은 맥락이 살아 있는 작업 중에 하고,
종결 때는 **옮기기만** 하게 만든다.

**대화 로그를 손으로 다시 쓰지 않는다** — 원문은 이미 자동 저장된다
(`~/.claude/projects/<프로젝트>/*.jsonl`). 필요한 건 **결정의 계기**뿐이다.

## 6. 종결 절차 — ★순서가 중요하다★

```
① 머리말을 [종결]로 (종결일 · 결과 한 줄 · 후속 링크)
② ★'상시로 갈 것'에 적립된 줄을 상시 문서로 옮긴다★
     옮길 것: 원칙 · 기제 · 재론 조건   /   남길 것: 그날의 실측 · 경과
③ 그다음 종결/YYYY-MM/ 으로 이동 + 그 문서를 가리키던 링크 전부 확인 + INDEX 갱신
```

**②를 건너뛰면 문서를 옮길 때 지식이 같이 사라진다.** 그리고 그 손실은 조용하다 —
폴더는 깔끔하고, 반년 뒤 같은 걸 다시 조사하기 전까지 아무도 모른다.

적립이 비어 있으면 여기서 한 번 훑는다. **단 이건 예외 경로다** — 매번 여기서 훑고 있으면
3장의 적립이 작동하지 않는 것이고, 고칠 곳은 6장이 아니라 3장이다.
