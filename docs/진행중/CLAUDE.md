> 월별로 가르지 않는다 — "몇 건이 열려 있나"가 한눈에 보여야 한다 (2장).
> 계기와 장 지도는 루트 CLAUDE.md 에 있다. 최종 확인: 2026-08-12
> 반증 조건: 없음 — 규칙은 합의다 (13장)
> 재론 조건: ★`하기로 한 것` 을 고치고 싶어진 적이 있을 때★ · 종결 절차 중간에 멈춘 적이 있을 때 ·
>            `## 실행` 을 몰아 쓴 적이 있을 때

## 14. 실행 누적 — ★계획을 고치지 않고 그 아래에 쌓는다★

문서가 여기 오면 아래 두 절이 붙는다.

```
## 실행      계획 항목을 하나씩 처리하며 그 자리에서 결과를 적는다
## 계획 밖   계획에 없던 것을 하게 됐을 때 — ★계획 칸을 고치지 않고 여기에★
```

**머리말 여섯 칸 중 ★손대지 않는 것은 둘★이다** (3장) — 나머지는 여기서 움직인다:

```
★안 고친다★  `계기` · `하기로 한 것` 의 ★항목 문장★   ← 이 둘이 대조의 기준선이다
고친다        체크박스 [ ] → [x]/[~]/[-]              항목 문장은 그대로 두고 표시만
              `상시로 갈 것`                          실행 중 한 줄씩 적립 (아래)
              `종결 조건`                             ★바꿨으면 `## 계획 밖` 에 왜인지★
              상태 표기 → [종결]/[폐기]                종결 때 한 번 (6장 ③)
```

**`종결 조건` 은 왜 고쳐도 되나**: 실행해 보면 조건 자체가 잴 수 없는 것이었음이
드러난다. 그대로 두면 문서가 영영 안 닫히고, 조용히 고치면 "닫으려고 조건을 낮췄다"가
안 보인다. **고치되 흔적을 남긴다** — 그게 `## 계획 밖` 의 용도다.

### ★계획을 고치지 않는다★ — 이게 이 장의 전부다

계획 항목이 실제와 달라졌을 때 손이 먼저 가는 곳은 `하기로 한 것` 칸이다.
**거기를 고치면 계획과 실제가 같아지고, 그 순간 이 문서는 아무것도 안 알려준다.**

```
항목대로 됐다          → `하기로 한 것` 의 [ ] 를 [x] 로 · ## 실행 에 결과 한 줄
항목이 틀렸다/불필요    → [ ] 를 [~] 로 · ★항목 문장은 그대로 두고★ ## 계획 밖 에 왜인지
안 하기로 했다          → [ ] 를 [-] 로 · ## 계획 밖 에 왜인지
계획에 없던 걸 했다     → ## 계획 밖 에 새 줄 · ★위에는 안 올린다★
★새 지시가 왔다★       → ## 계획 밖 에 ★사용자 말 원문 그대로★ + 그래서 뭘 더 하게 됐는지
                         ★`계기` 칸에 이어붙이지 않는다★ (3장)
```

**새 지시를 계기에 이어붙이지 않는 이유는 ★3장 정본★이다.**
한 줄로: **계기는 문서가 태어난 이유이고, 그건 하나뿐이다.**

**왜**: 이 문서가 종결됐을 때 남는 가장 큰 값은 결과가 아니라
**"처음 생각과 어디가 달랐나"** 다. 결과는 코드와 상시 문서에도 있지만,
차이는 여기 말고 아무 데도 없다. 계획을 덮어쓰면 그게 사라진다.

★계획 스냅샷이 `원본/잠정/` 에 있어도 여기서 안 고친다★ — 대조하러 두 파일을
열어야 하면 아무도 안 연다. **한 문서 안에서 위아래로 보여야 대조가 실제로 일어난다.**

### `## 실행` 에 무엇을 적나

**그 자리에서 적는다.** 항목 하나를 처리한 순간이다. 나중에 몰아 쓰면 회고가 되고,
회고는 잘된 것만 적는다.

```
적는다        실측값 · 실패와 그 원인 · 판단이 갈린 지점과 고른 쪽
안 적는다     명령 로그 · 코드 diff — 그건 저장소와 대화 로그가 갖는다
```

★실패를 지우지 않는다★. 헛돈 시도가 다음 사람이 가장 아쉬워하는 기록이다.

### `상시로 갈 것` — 실행 중에 적립한다

"이건 이 작업이 끝나도 남는 지식이다" 싶은 게 나오면 **그 순간 한 줄** 머리말 칸에 적는다.
어디로 옮길지까지 적으면 종결 때 판단이 필요 없다.

**왜**: 이 규약에서 **되돌릴 수 없는** 단계가 6장 ④ (지식 이관)인데, 그걸
문서를 빨리 닫고 싶은 순간에 요구하면 건너뛴다. 판별은 맥락이 살아 있는 실행 중에 하고,
종결 때는 **옮기기만** 하게 만든다.

## 6. 종결 절차 — ★순서가 중요하다★

```
① 계획 항목이 전부 [x]/[~]/[-] 인가 · 종결 조건이 찼는가 확인
② ★원본/진행중/YYYY-MM/ 에 이 시점 그대로 복사★ (16장)
     ★아무것도 고치기 전이다★ — 아래 ③④가 문서를 다시 쓰는 단계다
③ 머리말을 [종결]로 (종결일 · 결과 한 줄 · 후속 링크)
④ ★'상시로 갈 것'에 적립된 줄을 상시 문서로 옮긴다★
     옮길 것: 원칙 · 기제 · 재론 조건   /   남길 것: 그날의 실측 · 경과 · 계획과의 차이
     ★옮긴 줄마다 출처 사건 파일명을 단다★ (13장)
⑤ 그다음 종결/YYYY-MM/ 으로 ★이동★ (이름 안 바꾼다)
⑥ ★경로가 박힌 링크만★ 고친다 (회의록 머리말 등)
     상시 문서가 새로 생겼으면 00_구조.md 의 트리와 `## 읽는 순서` 에 넣는다
     결정대장 ①절 `사건` 칸은 파일명뿐이라 고칠 게 없다 (4장)
```

**★②가 왜 맨 앞인가 — 이 절차의 급소다★**

스냅샷이 막으려는 것은 **종결 정리가 실행 기록을 덮는 것**이고 (16장),
그 정리가 바로 ③④다. **정리한 뒤에 뜨면 정리하기 전을 담을 수 없다** —
무엇을 지웠는지는 지운 뒤에는 알 수 없고, 지우는 손은 자기가 지운 걸 기억하지 않는다.

```
② 뒤에 뜬다   "실행이 끝났을 때 이랬다"        ← 이게 이 스냅샷의 이름이다 (16장)
③④ 뒤에 뜬다  "종결 정리까지 끝냈을 때 이랬다"  ← 종결본과 같다. 뜰 값이 없다
```

★①은 확인이지 수정이 아니라서 ② 앞에 있어도 된다.★ ②부터가 손대는 구간이고,
그 구간에 들어가기 직전이 스냅샷 시점이다. **잠정 쪽(5장)도 같은 모양이다** —
①(확정 조건 갱신)은 칸 하나를 결과로 바꿀 뿐 덮는 행위가 아니라 ② 앞에 남는다.

**④를 건너뛰면 문서를 옮길 때 지식이 같이 사라진다.** 그리고 그 손실은 조용하다 —
폴더는 깔끔하고, 반년 뒤 같은 걸 다시 조사하기 전까지 아무도 모른다.

적립이 비어 있으면 여기서 한 번 훑는다. **단 이건 예외 경로다** — 매번 여기서 훑고 있으면
14장의 적립이 작동하지 않는 것이고, 고칠 곳은 6장이 아니라 14장이다.

**★단계 번호를 2026-08-12 에 한 번 옮겼다★** — 옛 ④(스냅샷)가 ② 로 올라오고
옛 ②③(머리말 · 이관)이 ③④ 로 밀렸다. 규약 안의 인용 12곳을 같이 고쳤다.
사건이 0건이라 규약 밖에는 인용이 없었고, **그래서 지금이 가장 싼 시점이었다.**
★다시는 옮기지 않는다★ (2장이 파일 번호에 대해 봉인한 것과 같은 이유).

### 실행 중에 접기로 하면 — ★같은 문으로 나간다★

다 하고 닫는 것만 종결이 아니다. **중간에 접는 것도 여기서 나간다** — 나가는 문은 하나다.

```
① 남은 항목을 [-] 로 (안 하기로 한 것) · `## 계획 밖` 에 왜 접는지
     ★여기만 원 절차와 다르다★ — ①이 '확인'에서 '표시'로 바뀐다
② 스냅샷 — ★그대로★ (접는 것도 정리 전에 뜬다)
③ 머리말을 ★[폐기]★ 로 (폐기일 · 왜 죽었나 한 줄)   ← [종결] 대신 이것만 다르다
④⑤⑥ 은 그대로 밟는다 — ★실행이 있었으니 스냅샷도 뜬다★ (잠정 단계 폐기와 다른 점)
계획이 통째로 틀려서 접는 것이면 → 이어서 잠정/ 에 새 계획 (15장과 같은 모양)
```

**④(지식 이관)를 특히 건너뛰지 마라.** 접은 작업에서 나오는 *"이 방법은 안 된다"* 는
성공한 작업의 결론만큼 값이 나간다 — 없으면 반년 뒤 같은 길로 다시 들어간다.

**★진행중 → 잠정 으로 되돌아가지 않는다.★** 되돌리면 `원본/잠정/` 스냅샷이 붕 뜨고,
다시 확정할 때 **"계획이 확정됐을 때 이랬다"가 두 벌**이 되어 어느 쪽이 그 사건의
계획인지 알 수 없게 된다. 접는 것과 다시 세우는 것은 **다른 문서**다.

### 종결 후에 수정할 거리가 생기면

**★종결 문서를 고치지 않는다★** — `잠정/` 에 새 계획을 연다 (15장).
