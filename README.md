# 문서 관리 규약

이 저장소는 **규약 자체를 만드는 곳**이다. 실제 프로젝트 문서가 아니라
"문서를 어떻게 만들고 옮기고 닫나"를 정한 규칙이 들어 있다.

- 규칙의 입구는 `CLAUDE.md` (루트) — 장 지도가 거기 있다
- 구조의 정본은 `docs/00_구조.md`
- **이 파일은 규칙이 아니다** — 장 번호가 없고, 여기 적힌 것은 규약이 아니라 ★열려 있는 문제★다

(*"차 있는 게 정상"*)으로 비정상 상태다. 완주를 해보면 ★읽어서는 안 보이는 것★이
나온다. 사례로는 규약 개정처럼 규칙을 의식하며 하는 작업보다 ★규약과 무관한 일반
작업★이 좋다 — 규칙이 자연 발동하는지까지 같이 보인다.

## 낡았는지 확인하는 법

위 숫자가 이 파일의 유일한 검사다. **다시 재서 늘었으면 문제는 그대로다.**

```powershell
# 규약 전체 분량 (한글이라 -Encoding utf8 을 빼면 깨진다)
$f = @('CLAUDE.md','docs/CLAUDE.md','docs/잠정/CLAUDE.md','docs/진행중/CLAUDE.md',
       'docs/종결/CLAUDE.md','docs/원본/CLAUDE.md','docs/회의록/CLAUDE.md',
       'docs/00_구조.md','docs/01_기술스택.md','docs/02_만드는것.md','docs/03_결정대장.md',
       'docs/04_규약근거.md')
($f | ForEach-Object {
    ((Get-Content $_ -Raw -Encoding utf8) -replace "`r`n","`n").TrimEnd().Length
} | Measure-Object -Sum).Sum

# 종결되어 보존된 사건 수 (산출물을 지웠으면 완주 이력과 무관하게 0 이다)
(Get-ChildItem docs/종결 -Recurse -Filter *.md -EA SilentlyContinue |
    Where-Object Name -ne 'CLAUDE.md').Count
```
