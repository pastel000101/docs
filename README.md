# 문서 관리 규약

이 저장소는 **규약 자체를 만드는 곳**이다. 실제 프로젝트 문서가 아니라
"문서를 어떻게 만들고 옮기고 닫나"를 정한 규칙이 들어 있다.

- 규칙의 입구는 `CLAUDE.md` (루트) — 장 지도가 거기 있다
- 구조의 정본은 `docs/00_구조.md`
- **이 파일은 규칙이 아니다** — 장 번호가 없고, 여기 적힌 것은 규약이 아니라 ★열려 있는 문제★다

---

## 열려 있는 문제 — 규칙이 줄지 않는다

**2026-08-12 기준으로 아직 안 풀렸다.**

분량이 38,357 → 49,921자(**1.3배**)가 됐다. 중복을 10곳 줄였는데도 늘었다 —
재론 조건 7개와 새 규칙들이 더 컸다.

즉 **"규칙에 소멸 경로가 없어 단조 증가한다"** 는 문제는 아직 안 풀렸다.
9장이 문서에 대해 *"만들 기준과 지울 기준은 둘이 한 쌍이다"* 를 세웠는데,
**규칙 자신에게는 그 쌍이 없다.** 만드는 문만 있고 나가는 문이 없다.

오늘 넣은 **재론 조건이 그 첫 장치**다 (13장 · 규칙 파일 7개 머리말).
규칙이 안 지켜지는 순간이 드러나면 그때 고치거나 지울 근거가 생긴다.
다만 그건 **실제로 문서를 굴려봐야 작동하고**, 지금 이 저장소의 사건은 여전히 **0건**이다.

### 그래서 다음에 할 일 — 규칙을 더 쓰는 게 아니다

★작은 일 하나를 `잠정/` 부터 `종결/` 까지 통과시켜 본다.★

규약이 44,000자가 넘는데 **한 건도 처리한 적이 없다.** 0장은
*"`잠정/` `진행중/` 은 차 있는 게 정상"* 이라고 하므로, 지금은 규약 자신의 기준으로
비정상 상태다. 완주를 한 번 해보면 **읽어서는 안 보이는 것**이 나온다 —
지금까지 발견한 가장 큰 결함(종결 스냅샷이 정리 뒤에 떠서 목적을 달성 못 하던 것)도
실제 절차를 따라가 보고서야 잡혔다.

**첫 사례로 쓸 만한 것**: 다음번 규약 개정. `CLAUDE.md` 1장이 문턱을 정해 뒀다 —
장을 새로 만들거나 지우거나, 단계 번호를 옮기거나, 폴더를 늘리고 줄이는 개정은
**사건이므로 잠정 문서를 연다.** 이제 "무엇이 사건인가"가 판정 가능하다.

## 낡았는지 확인하는 법

위 숫자가 이 파일의 유일한 검사다. **다시 재서 늘었으면 문제는 그대로다.**

```powershell
# 규약 전체 분량 (한글이라 -Encoding utf8 을 빼면 깨진다)
$f = @('CLAUDE.md','docs/CLAUDE.md','docs/잠정/CLAUDE.md','docs/진행중/CLAUDE.md',
       'docs/종결/CLAUDE.md','docs/원본/CLAUDE.md','docs/회의록/CLAUDE.md',
       'docs/00_구조.md','docs/01_기술스택.md','docs/02_만드는것.md','docs/03_결정대장.md')
($f | ForEach-Object {
    ((Get-Content $_ -Raw -Encoding utf8) -replace "`r`n","`n").TrimEnd().Length
} | Measure-Object -Sum).Sum

# 지금까지 처리한 사건 수 (0 이면 아직 한 번도 안 굴렸다)
(Get-ChildItem docs/종결 -Recurse -Filter *.md -EA SilentlyContinue |
    Where-Object Name -ne 'CLAUDE.md').Count
```

| 잰 날 | 분량 | 종결된 사건 | 메모 |
|---|---|---|---|
| 2026-08-12 (기준선 `83bc6f1`) | 38,357 | 0 | 검토 전 |
| 2026-08-12 | 49,921 | 0 | 모순 해소 + 재론 조건 도입 + 이 파일 추가 후 |

> ★이 표를 고칠 때는 ★재고 나서★ 적는다★ — 처음 적은 값(49,810)이 이 파일을
> 쓰는 동안 이미 틀렸다. 루트에 README 를 가리키는 줄을 넣느라 111자가 늘었는데,
> 그 줄을 넣은 것도 규약 수정이기 때문이다. **재는 행위가 재는 대상을 바꾼다.**

**줄어든 줄이 한 번이라도 기록되면 그때 이 절을 다시 쓴다.**
늘기만 하는 동안은 고칠 게 아니라 **아직 못 고친 것**이다.
